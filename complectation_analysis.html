ЧПУ против GET-параметров: Анализ подходов конкурентов

У некоторых крупных конкурентов комплектация передается исключительно через GET-параметры. Давайте разберем, почему они так делают и какие у этого скрытые минусы:

Пример: РОЛЬФ (rolf.ru)

Каталог построен как динамический SPA-фильтр на фронтенде:

/cars/new/?page=1&city_id=1&brand_id%5B0%5D=2192&model_id%5B0%5D=8503&complectation%5B0%5D=Max

Проблема: Поисковые боты (Яндекс/Google) экономят краулинговый бюджет и крайне плохо ранжируют URL с закодированными массивами параметров (%5B0%5D).

Пример: Авторай (avtoray.ru)

Использование GET-параметров для мультивыбора:

/cars/new/lada/granta?complectations=lada-granta-classic-9&complectations=lada-granta-classic-4

Обоснование: Пользователь выбрал одновременно 2 комплектации. Для мультивыбора ЧПУ физически невозможен, поэтому фильтрация корректно уходит в GET.

В витрине Юг-Авто уже сейчас успешно применяется гибридная модель для кузовов, трансмиссий и двигателей. Для комплектаций оптимально реализовать аналогичный алгоритм:

1. Одиночный выбор (1 комплектация) → ЧПУ
https://yug-avto.ru/cars/new/lada/granta/classic/
  • Формирует уникальный H1, Title и Description.
  • Выводит вилку цен («от X руб.»), опции и авто в наличии.
  • Автоматически попадает в sitemap-cis-new.xml.
  • Используется как посадочная для Яндекс.Директ.
2. Мультивыбор (2+ комплектации) → GET
https://yug-avto.ru/cars/new/lada/granta/?equipment=classic,comfort
  • Быстрая интерактивная фильтрация на клиенте.
  • Параметр canonical указывает на базовую страницу модели /cars/new/lada/granta/.
  • Поисковая база защищена от сотен мусорных комбинаторных дублей.
💡 Важное правило для карточек авто: URL самого автомобиля сохраняет стабильный 4-уровневый вид /cars/new/lada/granta/1124508/, чтобы изменения комплектации в 1С не приводили к поломке ссылок и редиректам.

Пошаговый план внедрения

1

Доработка базы данных и нормализатора (`yapps`)

Добавление колонки `code` в таблицу `yapps_app_cis_equipments`. Настройка автоматической генерации уникальных латинских слагов (например, `ultimate`, `flagship`, `classic`) при синхронизации с AutoCRM.

2

Доработка Go API (`atest.yug-avto.ru/go/`)

Расширение эндпоинтов `/filter` и `/vehicles` поддержкой слага комплектации (как одиночного в path, так и массива через GET). В `meta.go` реализация логики для уровня `level = "equipment"` (генерация H1, Title, Description, вилки цен от X руб. и хлебных крошек).

3

Обновление роутера Битрикс (`YAppShowroom`)

Модификация метода `makeFilter()` и `makeFilterUrl()` в `YApp.Showroom.class.php`: одиночная комплектация формирует ЧПУ-путь, мультивыбор уходит в GET-параметры. Настройка тега `canonical` для мультивыбора.

4

Верстка UI и генерация Sitemap

Создание блоков/табов комплектаций на странице модели и верстка посадочной страницы комплектации. Обновление `makeSitemap.php` для автоматической выгрузки ЧПУ-страниц комплектаций в XML-карту сайта.
