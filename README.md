# yug-avto.ru

Корпоративный сайт автохолдинга на **1С-Битрикс**: каталог автомобилей, сеть дилеров, API и SEO.

## Стек

- **1С-Битрикс** (PHP) — CMS и шаблоны
- **Кастомный API** — `YAApi.php`, `api/`
- **Cron** — фоновые задачи
- **SEO** — генерация sitemap, индекс, SEO-шаблоны для новых/б/у авто

## Структура

| Раздел | Назначение |
|--------|-----------|
| `cars/`, `brands/`, `offers/` | Каталог ТС (новые/б/у) |
| `dealerships/` | Сеть дилеров |
| `corporate/` | Корпоративные страницы |
| `api/`, `YAApi.php` | API-слой |
| `cron/` | Фоновые задачи |
| `sitemap*.xml`, `sitemap.php` | SEO-генерация |

## SEO-работа

- Генерация sitemap для новых/б/у авто и CIS-брендов
- Управление индексацией (ignore Indexing, плоские индексы)
- Оптимизация URL-шаблонов

## Статус

Боевой сайт, активная разработка.
